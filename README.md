# 🥔 포테이토 길드 (Potato Guild)

실존 유명 투자자를 패러디한 AI 페르소나들이 종목을 분석·토론하고, 모의투자자 "포테이토"가
그 조언을 바탕으로 가상 계좌(1,000만원)를 굴리는 개인용 주식 분석 프로젝트입니다.

> ⚠️ **면책 조항**: 이 프로젝트는 교육/개인 학습 목적으로 제작되었습니다. 여기 등장하는 캐릭터는
> 실존 인물의 실제 발언이 아니라 그들의 공개적으로 알려진 투자 철학에서 영감을 받은 AI 패러디이며,
> 실제 그 인물의 견해나 보증이 아닙니다. 이 프로젝트의 결과물은 투자 조언이 아니며, 실제 투자에 대한
> 책임은 전적으로 사용자 본인에게 있습니다. 친구에게 공유할 때도 이 점을 꼭 함께 알려주세요.

## 왜 이렇게 설계했나 (비용 구조)

원래 7명의 분석가는 **Gemini 무료 티어**로 돌려서 비용을 0원으로 유지했는데, 모델마다
무료 일일 한도가 제각각이고(`gemini-3.6-flash`는 하루 20회로 확인됨) 구글이 예고 없이
모델 세대를 바꾸는 바람에 자동화가 계속 429(요청 한도 초과)로 막히는 문제를 겪었습니다.
그래서 7명 분석가와 멍거를 **전부 Claude(Haiku/Sonnet)로 통일**했습니다 — 이미 멍거용으로
등록해둔 `ANTHROPIC_API_KEY` 하나를 그대로 재사용하고, Haiku가 워낙 저렴해서(입력
$1/백만 토큰, 출력 $5/백만 토큰 수준) 매일 자동 실행해도 한 달에 몇천 원 수준입니다.
Gemini 무료 티어로 돌아가고 싶을 경우를 대비해 `core/llm_client.py`의 `call_gemini_analyst`
함수는 그대로 남겨뒀습니다(현재는 어디서도 호출하지 않음).

실제 매수/매도 판단(점수 계산, 리스크 거부권, 포지션 사이징)은 LLM이 아니라
`core/guildmaster.py`, `core/potato.py`의 **결정론적인 코드 규칙**으로 처리합니다 —
돈과 관련된 판단은 매번 같은 입력에 같은 결과가 나와야 신뢰할 수 있기 때문입니다.

## 합의된 실행 규칙

- 가상 시드머니: **1,000만원**
- 7명의 의견을 확신도(1~5) 가중 합산 → **종합 스코어 ±8점 이상**일 때만 매매 실행, 그 외엔 관망
- **탈레브가 위험 경고를 내리면 다른 의견과 무관하게 무조건 관망** (리스크 거부권)
- 포지션 크기: 스코어 강도에 따라 자산의 5%(약함) / 10%(보통) / 15%(강함)
- 동시 보유 **최대 5종목** (분산 강제), 항상 자산의 **20% 이상 현금 유지**
- 매도 신호가 뜨면 보유 물량 전량 청산 (초보자 기준 단순화)

## 오픈소스에서 참고한 기법 (TauricResearch/TradingAgents)

캐릭터를 "학습"시킨다는 건 모델 자체를 재훈련(파인튜닝)하는 게 아니라, 검증된 오픈소스
멀티 에이전트 트레이딩 프레임워크의 **설계 기법을 프롬프트/로직에 반영**하는 방식입니다.
TauricResearch/TradingAgents를 참고해 아래 3가지를 추가했습니다.

1. **데이터 근거 강제** (`config/personas.py`) — 모든 캐릭터의 프롬프트에 "주어진 데이터에
   없는 내용은 지어내지 마라"는 문구를 추가해 할루시네이션을 줄였습니다.
2. **강세/약세 구조화된 토론** (`core/analysts.py`의 `run_bull_bear_debate`) — 피터 린치(강세)와
   마이클 버리(약세)가 1차 의견을 먼저 낸 뒤, 서로의 주장을 보고 한 번 반박/재판단하는 토론
   라운드를 거칩니다. Claude Haiku 호출이 종목당 7회 → 9회로 늘지만 비용은 여전히 미미합니다.
3. **회고(reflection) 메모리** (`core/memory.py`, `data/memory.json`) — 같은 종목에 대한 과거
   매수/매도 판단이 실제로 맞았는지(가격 변동으로) 코드가 계산해서, 다음 판단 때 멍거에게
   참고 자료로 전달합니다. 판단은 여전히 결정론적 코드가 하고, LLM은 그 회고를 브리핑에
   자연스럽게 녹여내기만 합니다.

## 목표가 / 손절가 (매수 신호일 때만 표시)

"어떤 가격에 사서 어떤 가격에 팔아야 하는지"까지 감을 잡을 수 있도록, **매수 신호가 나왔을 때만**
아래 규칙 기반 가이드라인을 함께 보여줍니다. 이건 미래 가격을 "예측"하는 게 아니라, 최근 가격
구간과 변동성을 근거로 한 참고용 숫자입니다.

- **목표가** = 최근 20거래일 저항선 (그 기간 동안 고점 부근에서 매도 압력이 있었던 가격대)
- **손절가** = 최근 20거래일 지지선 − ATR(14일 평균 실질 변동폭) × 0.5
  (종목 고유의 "정상적인 출렁임" 만큼 여유를 둬서, 일시적 변동성에 바로 손절당하지 않도록 함)
- **손익비** = (목표가 − 진입가) ÷ (진입가 − 손절가) — 1을 넘을수록 잠재 이익이 위험보다 큼

현재가가 이미 저항선 위이거나 지지선 아래처럼 계산이 억지스러워지는 경우엔 숫자를 억지로
보여주지 않고 생략합니다(`core/guildmaster.py`의 `_compute_price_levels`). 계산 로직은
`core/data_fetch.py`(ATR/지지선/저항선)와 `core/guildmaster.py`(목표가/손절가/손익비)에
있고, `tests_manual.py`에 결정론적 단위 테스트가 있습니다.

## 로드맵 (진행 중인 확장 작업)

기존에는 종목 하나씩 지정해서 분석했는데, 아래 3가지를 단계적으로 추가하는 중입니다.

1. **목표가/손절가 (완료)** — 위 섹션 참고.
2. **다종목 자동 스크리닝 (예정)** — 코스피/코스닥 시가총액 상위 종목을 큐레이션된 티커
   목록(yfinance 기반, KRX 로그인 정책 변경으로 `pykrx`는 사용하지 않음)으로 먼저 가볍게
   훑은 뒤, 유망한 후보에 대해서만 9인 전문가 딥다이브를 돌리는 방식.
3. **토스증권 계좌 연동 (예정, 사용자 작업 대기 중)** — 토스증권 Open API(`corp.tossinvest.com`)로
   실제 보유 종목/잔고를 가져와 매수/매도 "신호 알림"에 반영합니다. 실제 주문 체결은 자동화하지
   않고 항상 사용자가 직접 하는 것으로 범위를 정했습니다. 시작하려면 사용자가 토스증권 Open API
   개발자 신청을 완료해 `client_id`/`client_secret`을 발급받아야 합니다.

```
potato-guild/
├── main.py                    # 실행 진입점

├── core/
│   ├── data_fetch.py          # 가격/재무(yfinance)/뉴스(무료 RSS) 수집
│   ├── llm_client.py          # Claude(Haiku/Sonnet) 호출 (REST 직접 호출, 모델 티어링)
│   │                          #   - call_gemini_analyst는 미사용 폴백으로 남겨둠
│   ├── analysts.py            # 7명 분석가 실행 + 강세/약세 구조화된 토론
│   ├── guildmaster.py         # 점수 계산 + 리스크 거부권 + 멍거 브리핑(회고 반영)
│   ├── memory.py              # 과거 판단 회고(reflection) 기록/계산
│   ├── potato.py              # 모의투자 실행 엔진 (포지션 사이징/현금관리)
│   └── notify.py              # 텔레그램 알림
├── data/portfolio.json        # 포테이토의 모의 계좌 상태 (자동 갱신됨)
├── data/memory.json           # 과거 판단 회고 기록 (자동 갱신됨)
├── tests_manual.py            # 핵심 금융 로직 검증 스크립트
└── .github/workflows/guild_run.yml   # 정기 자동 실행 (무료, GitHub Actions)
```

## 시작하기

### 1. 필요한 API 키 준비

| 키 | 용도 | 발급처 | 비용 |
|---|---|---|---|
| `ANTHROPIC_API_KEY` | 7명 분석가(Haiku) + 멍거 브리핑(Sonnet) | https://console.anthropic.com | 저비용 종량제 (월 몇천 원 수준) |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | 알림 (선택) | @BotFather 에게 `/newbot` | 무료 |
| `GEMINI_API_KEY` | (선택, 현재 미사용 폴백) | https://aistudio.google.com/apikey | 무료 (카드 불필요) |

### 2. 로컬에서 테스트

```bash
pip install -r requirements.txt
cp .env.example .env          # 키 채워넣기

# 핵심 로직만 먼저 검증 (API 키 없이도 가능)
python tests_manual.py

# API 키 없이 전체 파이프라인 구조 확인
POTATO_GUILD_MOCK=1 python main.py AAPL

# 실제 키를 넣은 뒤 진짜 분석 실행
python main.py 005930.KS
```

### 3. GitHub Actions로 24시간 자동화 (무료)

1. 이 폴더를 **본인의 GitHub 저장소**로 올립니다 (퍼블릭 레포로 만들면 Actions 실행 시간이 완전 무료입니다).
2. 저장소 Settings → Secrets and variables → Actions 에서 위 키들을 등록합니다
   (`GEMINI_API_KEY`는 현재 미사용이라 생략해도 됩니다).
3. `.github/workflows/guild_run.yml`의 cron 스케줄과 종목 코드를 원하는 대로 수정합니다.
4. Actions 탭 → "포테이토 길드 정기 소집" → Run workflow 로 수동 실행도 가능합니다.
5. 실행이 끝나면 `data/portfolio.json`과 `data/memory.json`이 자동으로 커밋되어
   계좌 상태와 판단 회고 기록이 저장소에 계속 누적됩니다.
